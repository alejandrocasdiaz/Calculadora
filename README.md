# 📌 Calculadora en Java  
Este es un proyecto de una calculadora básica en **Java**, ejecutada por consola. Permite realizar operaciones matemáticas como suma, resta, multiplicación, división, raíz cuadrada y potencia.  

## 📜 Características  
✔️ Menú interactivo.  
✔️ Validación de entrada para evitar errores.  
✔️ Uso de métodos separados para cada operación.  
✔️ Control de errores (ejemplo: evitar división por 0 o raíces de números negativos).  

## 🚀 Requisitos  
🔹 **JDK 8 o superior**  
🔹 **IDE como Eclipse, VS Code**  

## 📌 Uso  
1️⃣ Clona el repositorio:
```
git clone https://github.com/alejandrocasdiaz/Calculadora.git
```
2️⃣ Abre el proyecto en un IDE compatible.<br>
3️⃣ Compila y ejecuta el archivo calculadora.java.
